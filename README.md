# CatBud tools

## 已實現的功能

- 可以自己修改功能按鍵了(在按鍵設定內)
- 在貓芽的特附附魔書上按住按鍵可以顯示特附資訊
- 自定義tooltip位置
- 擴充到所有貓芽特殊物品(應該做一半就是了)

## 還沒實現的功能
- 遊戲內指令指引(用指令實現)

## 如何下載
等我覺得可以release的時候你可以從右邊載，或者自己去action抓artifact   
你也可以選擇下載整個source下來，然後   
```
./gradlew.bat build
```
他會將build出來的東西放在./build/lib內
記得用JDK 21以上編譯

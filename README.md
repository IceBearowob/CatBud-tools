# CatBud tools

## 功能列表

- 在貓芽的特附附魔書及特殊物品可以顯示說明
- 遊戲內貓芽指令指引
- 自定義Tooltip位置和顯示方法

## 版本
CatBud Tools - 1.0.0-r9-b14-1.21.11  
目前支援Minecraft版本:1.21.11、26.2
### 依賴項
必須安裝[YetAnotherConfigLib](https://modrinth.com/mod/yacl)!

## 如何下載
在右邊的release下載，模組會永遠保持在最新版本

# CatBud tools

## 已實現的功能

- 在貓芽的特附附魔書及部分特殊物品上按住按鍵可以顯示相關說明
- 自定義tooltip位置
- 遊戲內貓芽指令指引(還沒完整上去)

## 還沒實現的功能
- 開Fork支援26.2
- 優化跟更新內容...還有避免ㄧ些奇怪的問題(就是說你為啥要帶著這模組去玩其他伺服器)

## 如何下載
等我覺得可以release的時候你可以從右邊載，或者自己去action抓artifact   
你也可以選擇下載整個source下來，然後   
```
./gradlew.bat build
```
他會將build出來的東西放在./build/lib內
記得用JDK 21以上編譯
